# Tickets Booking Agency

A cross-platform Flutter mobile application designed for event and travel booking.

The application allows users to browse available offers, explore trips, view trip details, manage bookings, and complete reservation workflows through a simple and user-friendly mobile interface.

---

## 🚀 Overview

Tickets Booking Agency provides a structured booking experience for users looking to discover and reserve events or travel opportunities.

The application uses Flutter for cross-platform development, GetX for reactive state management, and REST APIs for communication with backend services.

---

## ✨ Features

### 🎟️ Offers

- Browse available offers
- View offer details
- Explore available trips
- Display structured trip information

### 📅 Booking

- Select available trips
- Create bookings
- Manage reservations
- View booking information
- Booking confirmation workflow

### 🔌 API Integration

- REST API integration
- Remote data management
- API-based booking operations
- Structured application data flow
